# Glossary

The project's recurring terms, one canonical name each, with a short definition and the design
file that owns the concept. The design files use the canonical name; a variant listed as "also"
reads the same where the context is clear. The kinds of class these terms name are cataloged in
[entities.md](entities.md).

Read when: a design file, a rule or a review uses a term you cannot place; naming a concept in a
design file, a KDoc or a review, so it uses the same word as everything else.

| Term                    | Meaning                                                                                                                                    | Owner                                                                                   |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------|
| Action                  | A store input its bootstrapper sends; callers never send one                                                                               | [mvi.md](mvi.md) "Store contract"                                                       |
| Android host            | The Android application module; it holds the `Application`, and its one project dependency is the composition root                         | [project-structure.md](project-structure.md) "Module kinds"                             |
| `api`, `impl`           | The visibility segment of a package: what outside code programs against, and everything else. Both are public across modules               | [module-anatomy.md](module-anatomy.md) "Packages"                                       |
| App graph               | The `@AppScope` component, one twin per platform in the composition root. Also: app graph twin                                             | [dependency-injection.md](dependency-injection.md) "Component hierarchy"                |
| Binder                  | The `bind(lifecycle, START_STOP)` wiring a controller sets up between stores                                                               | [mvi.md](mvi.md) "Controllers"                                                          |
| Bootstrapper            | What a store runs when it is created                                                                                                       | [state-restoration.md](state-restoration.md) "Screen restore protocol"                  |
| Call result             | `CallResult`: `Success` or an HTTP, network or other failure, returned by every network call                                               | [data-layer.md](data-layer.md) "Network"                                                |
| Child factory           | The function the root host passes to the root component; it builds a root child, with a fresh feature graph, for a config                  | [navigation.md](navigation.md) "Root stack"                                             |
| Component creator       | The `@KmpComponentCreate expect fun createDi<Name>Component(...)` whose body KSP writes. Also: creator, next to its component's name       | [dependency-injection.md](dependency-injection.md) "Creating graphs"                    |
| Composition root        | The module holding both app graphs, the one iOS framework and the entry object                                                             | [project-structure.md](project-structure.md) "Module kinds"                             |
| Controller              | The class that wires one owner's stores to each other and to the route                                                                     | [mvi.md](mvi.md) "Controllers"                                                          |
| Core module             | A module under `core-kmp`: composition root, DI-scope leaf, navigation, network, UI kit, persistence, test utilities                       | [project-structure.md](project-structure.md) "Module kinds"                             |
| Creator disposes        | Whoever creates a store, a scope or a subscription also closes it                                                                          | [principles.md](principles.md) "The creator disposes"                                   |
| Db model                | A model or enum other modules exchange with the persistence core module                                                                    | [data-layer.md](data-layer.md) "Persistence"                                            |
| Deep link               | A root config encoded for a notification; decoding never throws                                                                            | [navigation.md](navigation.md) "Deep links"                                             |
| Dependencies contract   | The interface listing what a graph reads from its parent: one per feature graph, one for the root graph                                    | [dependency-injection.md](dependency-injection.md) "Component hierarchy"                |
| Design token            | A typed UI constant in a `Dimens`, `Fonts` or `Colors` file                                                                                | [ui-compose.md](ui-compose.md) "Design tokens"                                          |
| Device test             | A test in `androidDeviceTest`, or in the Android host's `src/androidTest`, that runs on an emulator. Also: instrumented test               | [testing.md](testing.md) "Test map"                                                     |
| DI-scope leaf module    | The core module holding scopes, qualifiers and the platform context, with no binding and no project dependency. Also: DI-scope leaf        | [project-structure.md](project-structure.md) "Module kinds"                             |
| Domain model            | A feature's own model of the data it shows, even where another feature has a similar one                                                   | [data-layer.md](data-layer.md) "Sources and usecases"                                   |
| Entity                  | A Room table model, internal to the persistence core module                                                                                | [data-layer.md](data-layer.md) "Persistence"                                            |
| Entry module            | The module holding the root graph, root host, root content, screen hosts and the implementations of external contracts                     | [project-structure.md](project-structure.md) "Module kinds"                             |
| Entry object            | The Kotlin `object` in the composition root's `iosMain` that Swift calls. Also: iOS entry object                                           | [ios-host.md](ios-host.md) "Entry point"                                                |
| Executor                | The store part that runs intents and actions: it calls usecases, dispatches messages, publishes labels                                     | [mvi.md](mvi.md) "Executors and state"                                                  |
| Executor factory        | A function type that builds a store's executor, injected into its store factory                                                            | [mvi.md](mvi.md) "Executors and state"                                                  |
| External contract       | A contract a feature calls and the entry module implements, kept in an external module                                                     | [project-structure.md](project-structure.md) "How modules talk"                         |
| External module         | A contract-only `*-external` module                                                                                                        | [project-structure.md](project-structure.md) "Module kinds"                             |
| Feature graph           | The `@FeatureScope` component of one screen, built fresh for each screen component                                                         | [dependency-injection.md](dependency-injection.md) "Component hierarchy"                |
| Full regression         | The manual walk of every module's regression file, run from the root's full-regression file                                                | [documentation.md](documentation.md) "Regression"                                       |
| Host test               | A test in `androidHostTest`, or in the Android host's `src/test`, run on the JVM; under Robolectric where it reaches the Android framework | [testing-platforms.md](testing-platforms.md) "Android"                                  |
| Intent                  | A store input a caller sends through `accept`                                                                                              | [mvi.md](mvi.md) "Store contract"                                                       |
| iOS host                | The Xcode app and its Swift sources; not a Gradle module. Also: Swift app                                                                  | [project-structure.md](project-structure.md) "Module kinds"                             |
| iOS root holder         | The `iosMain` class that keeps one root per process and its saved-state string. Also: root holder                                          | [state-restoration.md](state-restoration.md) "iOS"                                      |
| Label                   | A one-time output of a store, which a controller maps to another store's intent or a callback                                              | [mvi.md](mvi.md) "Store contract"                                                       |
| Live root               | The root already built; a notification tap navigates it instead of rebuilding it                                                           | [navigation.md](navigation.md) "Deep links"                                             |
| Main store              | The store a screen's UI draws from; section stores report into it                                                                          | [mvi.md](mvi.md) "Main and section stores"                                              |
| Message                 | What an executor sends its reducer; callers never send one                                                                                 | [mvi.md](mvi.md) "Store contract"                                                       |
| Minified                | The Android build type that is `release` signed with the debug key                                                                         | [versioning-and-release.md](versioning-and-release.md) "Build types and configurations" |
| Module component        | An interface of `@Provides` functions for one module, mixed into the app graph or the root graph                                           | [dependency-injection.md](dependency-injection.md) "Module and platform components"     |
| Overlay state holder    | A `<Name>State` the root host builds and root content draws, such as a dialog's                                                            | [navigation.md](navigation.md) "Root-level elements"                                    |
| Permission session      | The per-process state of the notification permission flow every root shares. Also: notification permission session                         | [platform-mirroring.md](platform-mirroring.md) "Accepted asymmetries"                   |
| Platform component      | A component with platform bindings, with one twin of the same name per platform                                                            | [dependency-injection.md](dependency-injection.md) "Module and platform components"     |
| Platform context        | `PlatformContext`: Android's `Context`, an empty class on iOS, taken by both app graphs                                                    | [kmp.md](kmp.md) "Expect and actual"                                                    |
| Platform service        | A module kind: a capability with a common contract and per-platform implementations                                                        | [project-structure.md](project-structure.md) "Module kinds"                             |
| Regression file         | A module's manual test script, beside its README                                                                                           | [documentation.md](documentation.md) "Regression"                                       |
| Response model          | A `@Serializable` data class the network returns                                                                                           | [data-layer.md](data-layer.md) "Network"                                                |
| Root                    | One root host with its component context, root component and root graph. Android builds one per activity creation, iOS one per process     | [platform-mirroring.md](platform-mirroring.md) "Accepted asymmetries"                   |
| Root child              | The entry module's wrapper of one screen component, naming its section                                                                     | [navigation.md](navigation.md) "Root stack"                                             |
| Root component          | The Decompose component holding the root stack; not the root graph                                                                         | [navigation.md](navigation.md) "Root stack"                                             |
| Root config             | One destination of the root stack, a serializable `data object`                                                                            | [navigation.md](navigation.md) "Root stack"                                             |
| Root content            | The top composable of a root, drawn by both screen hosts                                                                                   | [navigation.md](navigation.md) "Root stack"                                             |
| Root graph              | The `@RootScope` component, parent of every feature graph, one per root                                                                    | [dependency-injection.md](dependency-injection.md) "Component hierarchy"                |
| Root host               | The common class that is one root: it builds the root component and the root-level elements' controllers                                   | [navigation.md](navigation.md) "Root stack"                                             |
| Root stack              | The single child stack of root configs; navigating replaces it whole                                                                       | [navigation.md](navigation.md) "Root stack"                                             |
| Root-level element      | UI beside the stack for the root's whole life, with a store and a controller and no screen component                                       | [navigation.md](navigation.md) "Root-level elements"                                    |
| Route                   | The composable that connects a controller to its screen                                                                                    | [ui-compose.md](ui-compose.md) "Screens and routes"                                     |
| Saved part              | What a screen component keeps in its `StateKeeper`: a snapshot or a marker                                                                 | [state-restoration.md](state-restoration.md) "Screen restore protocol"                  |
| Scope                   | A kotlin-inject lifetime annotation: app, root or feature                                                                                  | [dependency-injection.md](dependency-injection.md) "Scopes"                             |
| Screen component        | The Decompose component of one screen: its feature graph, stores, controller and saved part                                                | [navigation.md](navigation.md) "Screen components"                                      |
| Screen feature          | A module kind: one destination with its screen component, controller, stores, source and UI                                                | [project-structure.md](project-structure.md) "Module kinds"                             |
| Screen host             | The platform screen that builds a root and shows root content: the activity, or its iOS twin                                               | [platform-mirroring.md](platform-mirroring.md) "Mirror table"                           |
| Screen restore protocol | The order a screen component registers disposal, reads its saved part and replays it                                                       | [state-restoration.md](state-restoration.md) "Screen restore protocol"                  |
| Section                 | A destination of the root-level element that switches screens; each root child names one                                                   | [navigation.md](navigation.md) "Root-level elements"                                    |
| Section store           | A store for one part of a screen with several parts; not related to a section above                                                        | [mvi.md](mvi.md) "Main and section stores"                                              |
| Service                 | A network interface of backend endpoints and its implementation over the `HttpClient`                                                      | [data-layer.md](data-layer.md) "Network"                                                |
| Shared base module      | A module kind holding what several features share: a service, models, composables, strings                                                 | [project-structure.md](project-structure.md) "Module kinds"                             |
| Source                  | A feature's data contract returning a call result of domain models, and its implementation                                                 | [data-layer.md](data-layer.md) "Sources and usecases"                                   |
| Store                   | An MVIKotlin store: contract, factory, executor and reducer                                                                                | [mvi.md](mvi.md) "Store contract"                                                       |
| System message          | A user-facing failure message, sent through the provider and the controller, shown by the host                                             | [error-handling.md](error-handling.md) "Message path"                                   |
| Tap contract            | The external contract that turns a notification's target into what the platform carries: an intent or a payload                            | [platform-mirroring.md](platform-mirroring.md) "Accepted asymmetries"                   |
| Tap target              | The root config a notification opens, with the payload key that carries it                                                                 | [navigation.md](navigation.md) "Deep links"                                             |
| Twin                    | A platform counterpart: the same simple name in each platform's package. Also: platform counterpart                                        | [platform-mirroring.md](platform-mirroring.md) "Twins"                                  |
| UI kit module           | The core module holding the theme, tokens, shared composables, coroutine contexts, system messages and paging                              | [project-structure.md](project-structure.md) "Module kinds"                             |
| UI model                | The immutable model a screen composable renders, mapped from store state                                                                   | [mvi.md](mvi.md) "Mappers and UI models"                                                |
| UI-only component       | A module kind: composables and tokens only; its state holder lives in its host                                                             | [project-structure.md](project-structure.md) "Module kinds"                             |
| Usecase                 | One operation with `execute`: module-local and concrete, or an exported interface                                                          | [data-layer.md](data-layer.md) "Sources and usecases"                                   |
| Usecases wrapper        | A data class bundling the usecases one executor needs                                                                                      | [data-layer.md](data-layer.md) "Sources and usecases"                                   |
